Diese Seite enthält Informationen zur Funktionalität laufender Berechnungen.


Beim Ausführen von Berechnungen wird der resultierende Wert eines Ausdrucks als Anfang eines neuen Ausdrucks verwendet.

Sie werden erreicht, indem nach Erhalt eines Ergebnisses einer der Operatoren ausgewählt wird.

Wenn Sie die Funktion zum Ausführen von Berechnungen nicht nutzen möchten, können Sie einfach mit der Eingabe eines neuen Operanden beginnen.
